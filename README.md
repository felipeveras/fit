# App Fit

V1: Android reads Health Connect and syncs daily metrics and activities directly to Supabase. Supabase Auth and row level security isolate each user's data.

The current database contract and deployment notes are in [supabase/README.md](supabase/README.md). The detailed documents in `docs/` record earlier HOM-25 planning; their RPC, lease, writer, and Hermes designs are not the V1 implementation.
